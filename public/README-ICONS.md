# Missing Icon Files

The following icon files are referenced in the code but not present in the repository:

1. **favicon.ico** - Browser tab icon (16x16 or 32x32)
2. **icon.png** - App icon (32x32)
3. **apple-icon.png** - Apple touch icon (180x180)
4. **og-image.png** - Open Graph image for social sharing (1200x630)
5. **icon-192.png** - PWA icon (192x192)
6. **icon-512.png** - PWA icon (512x512)

## How to Create These Icons

You can create these icons from your logo or profile picture using:

1. **Online tools:**
   - https://realfavicongenerator.net/ (generates all sizes)
   - https://www.canva.com (for og-image)

2. **Design tools:**
   - Figma, Photoshop, or any image editor

3. **Requirements:**
   - Use your branding colors (gold #c9a961 on dark #0a0a0a background)
   - Keep designs simple and recognizable at small sizes
   - og-image should include your name and title "AI Engineer"

## Quick Fix

Until you create custom icons, you can:
1. Copy your logo (Assets/Logo.png) to public/icon.png
2. Resize it to different sizes for other icons
3. Create a simple og-image with text on a dark background
